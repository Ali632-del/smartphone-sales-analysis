# Smartphone Sales Analysis

## Project Overview
This project analyzes smartphone sales data to discover sales trends, top-performing brands, and key business insights.

## Objectives
- Analyze smartphone sales performance
- Identify top brands and models
- Visualize sales trends
- Build an interactive dashboard

## Tools Used
- Python
- Pandas
- Power BI
- Data Visualization

## Project Steps
1. Data Cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Sales insights extraction
4. Dashboard creation using Power BI

## Dashboard Features
- Total Sales
- Total Quantity Sold
- Average Price
- Brand Performance
- Sales Distribution

## Key Insights
- Some brands dominate the market share
- Certain price ranges generate the highest sales
- Sales vary significantly across different models

## Files
- dataset.csv → raw dataset
- smartphone_analysis.ipynb → analysis code
- dashboard.pbix → Power BI dashboard
- dashboard.png → dashboard preview
